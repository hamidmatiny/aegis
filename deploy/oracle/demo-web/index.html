Try to get something past it. That's the point of this page — type a message and watch the real defense pipeline decide what happens to it (same detectors, same policy engine, no LLM API keys required; runs on a mock model). Source on GitHub.

Be upfront about what this demo is: this instance runs on a free-tier 1GB server, so detectors use lightweight pattern-based backends, not the full trained models. And even the hardened, full-model version doesn't catch everything — our own adaptive red-team testing found real-model detectors converge to roughly the same ~48% bypass rate as these lightweight ones by round 3 of an adapting attacker. We publish that number so you find out from us, not from a bypass. Full methodology and numbers: RESULTS.md.
