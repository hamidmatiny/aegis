# Deploy AEGIS SMB Copilot to defenseaegis.org

Run these steps on the Oracle VM (or any host using the demo overlay). Assumes Phase 9 auth, Phase 10 billing, and Phase 11 site relaunch are merged to `main`.

## 1. Pull latest and credentials

```bash
cd /path/to/aegis
git fetch origin
git checkout main
git pull origin main

# Backfill any new env vars (SMB_SESSION_SECRET, ADMIN_*, STRIPE_*, etc.)
./scripts/generate-credentials.sh
```

## 2. Edit `.env` on the VM — required new variables

Add or confirm these (owner-provided secrets marked **owner**):

```bash
# Chat (Grok via model-router — owner provides XAI key)
SMB_CHAT_PROVIDER=grok
SMB_CHAT_MODEL=grok-4-fast
SMB_CHAT_MODEL_WALKTHROUGH=grok-4
XAI_API_KEY=<owner>

# Embeddings (OpenAI — Grok does not support embeddings)
SMB_EMBEDDING_PROVIDER=openai
SMB_EMBEDDING_MODEL=text-embedding-3-small
OPENAI_API_KEY=<owner>

# Token caps (defaults OK if omitted)
SMB_QA_MAX_TOKENS_FREE=500
SMB_QA_MAX_TOKENS_WALKTHROUGH=1200

# Auth (generated by generate-credentials.sh — verify ADMIN_PASSWORD_HASH is single-quoted in .env)
# ADMIN_USERNAME=smbadmin
# ADMIN_PASSWORD=...
# ADMIN_PASSWORD_HASH='...'
# SMB_SESSION_SECRET=...

# SMB portal/cookie (root domain is the SMB front door — Phase 11)
SMB_PORTAL_BASE_URL=https://defenseaegis.org
SMB_COOKIE_SECURE=true
SMB_COOKIE_PATH=/

# Stripe (owner creates Product/Price + webhook in Stripe Dashboard)
STRIPE_SECRET_KEY=sk_live_...          # owner
STRIPE_WEBHOOK_SECRET=whsec_...        # owner — from webhook endpoint below
STRIPE_PRICE_ID_STANDARD=price_...     # owner
```

Verify bcrypt hash is not corrupted:

```bash
unset ADMIN_PASSWORD_HASH ADMIN_USERNAME ADMIN_PASSWORD
docker compose run --rm --no-deps smb-copilot \
  python -c "import os; print(os.environ['ADMIN_PASSWORD_HASH'][:7])"
# Must print: $2b$12  (not empty, not truncated)
```

## 3. Render nginx and rebuild portal (root paths)

```bash
# From repo root — setup.sh envsubst's nginx-demo.conf.template
./deploy/oracle/setup.sh

# Rebuild smb-portal — root-relative paths (defaults in docker-compose.demo.yml)
docker compose -f docker-compose.yml -f deploy/oracle/docker-compose.demo.yml \
  build smb-portal
```

## 4. Bring up the stack

```bash
docker compose -f docker-compose.yml -f deploy/oracle/docker-compose.demo.yml \
  up -d --build smb-copilot smb-portal postgres redis policy-engine model-router audit demo-proxy
```

## 5. Stripe webhook (register in Stripe Dashboard)

**Webhook URL (public):**

```
https://defenseaegis.org/api/smb/billing/webhook
```

Events to subscribe: `checkout.session.completed`

Copy the signing secret into `.env` as `STRIPE_WEBHOOK_SECRET`, then restart smb-copilot:

```bash
docker compose -f docker-compose.yml -f deploy/oracle/docker-compose.demo.yml restart smb-copilot
```

## 6. Public verification (not localhost)

```bash
# SMB landing at root
curl -sI https://defenseaegis.org/ | head -5

# Health (via API path)
curl -s https://defenseaegis.org/api/smb/healthz

# Admin login rate-limited path exists (expect 401 with bad creds, not 404)
curl -s -w "\nHTTP %{http_code}\n" -X POST https://defenseaegis.org/api/smb/auth/admin-login \
  -H 'Content-Type: application/json' \
  -d '{"username":"wrong","password":"wrong"}'
```

Manual browser checks:

1. Open `https://defenseaegis.org/` — signup-first SMB landing; “Continue as guest” is a secondary link.
2. Register a customer account, complete intake, ask a Q&A question — answer must **not** be a `[mock:...]` echo when Grok is configured.
3. `/billing` — Upgrade via Stripe (test mode first).
4. `/admin/login` — operator console; engine demo at `/admin/engine-demo` (not linked from public nav).

## 7. Nginx locations (Phase 11)

- `/` → smb-portal (public front door)
- `/api/smb/` → smb-copilot
- `/api/corp/` → corp-orchestrator (Phase 12 BEV / agents; admin session)
- `/api/smb/auth/register|login|admin-login` → stricter rate limit (`aegis_smb_auth` zone)
- `/v1/chat/completions`, `/agent-gate/*` → gateway/agent-gate (engine demo, admin-only UI)

Gateway/agent-gate routes remain for the relocated engine showcase (`/admin/engine-demo`).

## 8. Phase 12 — corp-orchestrator (BEV / agent corporation)

Additive service. Does **not** change SMB chat/billing/auth product paths.

### What gets deployed

| Piece | Detail |
|-------|--------|
| Service | `corp-orchestrator` on compose network port **8094** (`127.0.0.1:8094` published for ops) |
| SQL | `deploy/postgres/init/009_corp_agents.sql` — `agents` + `tasks` (+ pending_approval / queue_position via service migrations at startup) |
| Nginx | `/api/corp/` → `http://corp-orchestrator:8094/` (already in `nginx-demo.conf.template`) |
| Shared auth | `smb-session` (`aegis-smb-session`) — both `smb-copilot` and `corp-orchestrator` Dockerfiles install it; admin cookie `aegis_smb_session` |
| Portal | `/admin/company` — Bird's Eye View + CEO Trajectory (AdminGuard) |

### Initial production flags (safe first cutover)

**Leave these as-is on first deploy** so the owner can inspect the dashboard and manually trigger runs before any unattended API spend:

```bash
# In VM .env — Phase 12 first deploy defaults
CORP_FORCE_MOCK_LLM=true
CORP_SCHEDULER_ENABLED=false
CORP_HEALTHZ_URL=http://smb-copilot:8093/healthz
# Optional for MRR when owner enables real finance reads later:
# STRIPE_SECRET_KEY / STRIPE_PRICE_ID_STANDARD already used by smb-copilot
```

Do **not** set `CORP_FORCE_MOCK_LLM=false` or `CORP_SCHEDULER_ENABLED=true` until the owner explicitly decides to.

### Bring up corp + dependencies

```bash
cd ~/aegis
git pull origin main
./deploy/oracle/setup.sh   # re-render nginx so /api/corp/ is present

# Ensure .env has CORP_FORCE_MOCK_LLM=true and CORP_SCHEDULER_ENABLED=false
docker compose -f docker-compose.yml -f deploy/oracle/docker-compose.demo.yml \
  up -d --build --force-recreate \
  postgres redis policy-engine model-router agent-gate audit \
  smb-copilot smb-portal corp-orchestrator demo-proxy
```

Fresh Postgres volumes pick up `009_corp_agents.sql` automatically. Existing volumes: `corp-orchestrator` applies packaged SQL migrations on startup (`001`–`003`) and seeds **13** agents.

### Verify corp on the public host

```bash
# Agents seeded
docker compose exec -T postgres psql -U aegis -d aegis -t -c 'SELECT count(*) FROM agents;'
# Expect: 13

# Corp health (loopback on VM)
curl -s http://127.0.0.1:8094/healthz

# Public API (admin session cookie or internal token)
curl -s https://defenseaegis.org/api/corp/healthz
curl -s https://defenseaegis.org/api/corp/v1/bev/summary \
  -H "Authorization: Bearer $AEGIS_INTERNAL_TOKEN"

# Manual one-department mock run (scheduler still off)
curl -s -X POST https://defenseaegis.org/api/corp/v1/tasks/run \
  -H "Authorization: Bearer $AEGIS_INTERNAL_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"department":"engineering","team":"core_infra"}'
```

Browser: admin login → `https://defenseaegis.org/admin/company` (customer session must get 403 on `/api/corp/v1/*`).
